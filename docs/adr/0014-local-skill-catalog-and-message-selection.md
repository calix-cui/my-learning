# ADR-0014 账号级本地 Skill 目录与单条消息选择

- 日期 2026-11-18
- 状态已采纳
- 后续演进 [ADR-0013](0013-skills-as-method-packages.md)

## 背景

旧设计使用数据库创建 Skill，并在会话上挂载。聊天页为了显示挂载项，在切换会话时重新查询 Skill。用户要求本地安装与发现，设置只读，目录按账号复用，并保留显式选择和模型按需加载。

## 决定

- 新聊天从内置、本地共享与账号私有目录发现 Skill，以来源隔离的稳定键引用。
- 登录或刷新时初始化账号目录，设置页可重扫。元数据快照保存到现有账号设置表，供多个后端进程复用。
- 本条消息携带显式 Skill 键和可选目录版本。Runtime 按快照加载正文，按运行去重并保持审批恢复时的原版本。前端成功发送后清除本次选择。
- 模型可根据元数据请求加载 Skill。账号工具配置和 Policy 决定权限。
- 旧数据库 Skill 可导出为文件包。旧接口和记录暂留作兼容，网页只提供只读目录和说明。

## 代价

增加一个可空 JSON 字段，扫描是有界的同步文件读取。文件变化由用户在设置中扫描，当前没有后台文件监听。账号私有目录需要部署时分配并安装文件。参考资料沿用现有文本读取限制，脚本执行能力后续独立设计。

进程缓存实现较轻，但多进程需要额外失效通知。数据库元数据快照复用现有基础设施，可以直接在扫描后供其他进程读取，因此采用后者。
