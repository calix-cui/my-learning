# 商品管理后台｜视觉设计规范

| 项目 | 内容 |
| --- | --- |
| 版本 | v1.0（2026-11-06） |
| 设计画布 | 1440 × 900（桌面优先，最小可用宽度 1280） |
| 设计稿 | `docs/design/mockups/01..05-*.html`，导出图 `docs/design/images/01..05-*.png`（2880 × 1800，@2x） |
| 实现仓库 | `fullstack/product-admin/`（Vue3 + Element Plus），token 落在 `src/styles/index.css` |
| 上游依据 | `docs/product/product-admin-prd.md`、后端接口 `python/fastapi-demo/docs/api.md` |
| 覆盖页面 | 商品列表、新增/编辑商品弹窗、分类管理、概览、空态 |

## 1. 设计原则

1. **表格优先，装饰让位**：后台的核心动作是「找商品 → 改商品」，所有页面的视觉重心是表格行本身。去掉斑马纹、渐变、图标墙，仅用 1px 边框和 8px 圆角区分层级，让价格、库存、状态一眼可扫。
2. **一套 token 走到底**：颜色、字号、间距、圆角、阴影只允许来自本文第 2 节；页面里出现任何「临时调一下」的数值都视为缺陷。前端通过 `--pa-*` CSS 变量消费，Element Plus 主色同步覆盖，保证弹窗、分页、表格与设计稿同色同高。
3. **危险操作必须减速**：删除一律二次确认，危险按钮用红色实心并通过文案说明后果（不可恢复 / 先处理商品），危险色只出现在删除动作与库存为 0 的数字上。

## 3. 布局规格

```
┌──────────────┬────────────────────────────────────────────────────────────┐
│ 200px 侧栏    │ 56px 顶栏：页面标题 │ 面包屑 ········ 后端状态 · 用户        │
│ 品牌区 56px   ├────────────────────────────────────────────────────────────┤
│ 功能菜单      │ 内容区 padding 24px                                        │
│  · 概览       │  ┌ 统计卡 92px ─┬─ 统计卡 92px ─┬─ 统计卡 92px ─┐  gap 16│
│  · 商品管理   │  ┌ 搜索区 64px ───────────────────────────────┐           │
│  · 分类管理   │  ┌ 数据卡片：卡头 56 / 表格 / 分页条 64 ───────┐           │
│ 版本·接口状态 │                                                            │
└──────────────┴────────────────────────────────────────────────────────────┘
```

- **侧栏**：白底，右侧 1px `--border`；品牌区高 56px（28 × 28 主色渐变方块、圆角 8px + 「商品管理后台」14px/600）；菜单区四周留 12px，菜单项高 44px、圆角 6px、项内左右 12px、图标 16px 与文字间距 10px；选中态为 `--primary-50` 底 + `--primary-600` 文字 + 左侧 3px × 24px 主色竖条；底部固定「版本 v1.0 · 2026-11」与绿点「接口服务正常」（12px）。
- **顶栏**：白底，下边框 1px；左侧「页面标题 18px/600」+ 1px × 14px 竖向分割线 + 面包屑「首页 / 当前页」（13px，末级 `--text-2`）；右侧「已连接后端 · 127.0.0.1:8000」（12px，6px 绿点 + 光晕）+ 头像（28px 圆形，`--primary-50` 底、`--primary-700` 文字）+ 用户名 + 下拉箭头。
- **内容区**：纵向 flex，`gap: 16px`；只有「列表/表格卡片」可以 `flex:1` 吃掉剩余高度（分页条始终贴卡片底部），统计卡、搜索区、说明卡为固定高度。
- **对齐栅格**：所有卡片 `box-sizing: border-box`，宽度 100%；表格使用 `table-layout: fixed` + `<colgroup>` 固定列宽，列宽之和等于卡片内宽（1440 − 200 − 48 内容内边距 − 48 表格内边距 = 1144px），不使用百分比。
- **纵向预算（900px 画布）**：56 顶栏 + 24 内边距 + 92 统计 + 16 + 64 搜索 + 16 + 608 表格卡 + 24 = 900。

表格细则：表头高 44px、`#FAFBFC` 底、13px/500 `--text-3`、下边框 1px `--border`；表体行高 48px、14px `--text-2`、行下边框 1px `--border-light`、最后一行无边框；单元格左右内边距 12px、内容单行 `ellipsis`。

### 4.2 搜索区

- 结构：关键词输入框 260px（前置 14px 放大镜，左侧内边距 30px，占位「搜索商品名称，回车查询」）+ 分类下拉 180px（占位「全部分类」）+ 主按钮「查询」+ 默认按钮「重置」+ 右侧 12px 灰色提示「支持按商品名称模糊搜索，回车即可查询」。
- 回车 = 点击查询；重置清空关键词并把分类恢复为「全部分类」、页码回到第 1 页。

### 4.3 分页

左「共 N 条」（13px `--text-3`），右侧「10 条/页」下拉（32px 白底描边）+ 上一页 + 页码 + 下一页（32 × 32，圆角 6px）；当前页 `--primary-600` 实心白字，其余白底 `--border` 描边，禁用页文字 `#D1D5DB`、底色 `#FAFBFC`。每页条数可选 10 / 20 / 50。

### 4.4 表单弹窗（新增 / 编辑商品）

- 宽 480px，圆角 12px，`--shadow-lg`；卡头 56px（标题 16px/600 + 右上 20px 关闭图标）；卡体 `24px 24px 8px`；卡底 64px、`#FCFCFD` 底、右对齐「取消」+「确定」。
- 表单行：label 96px 右对齐（字号 14px `--text-2`，必填项前置红色 `*`）、控件区自适应、行间距 20px；控件高 32px。
- 字段顺序：商品名称（输入框内右侧显示 `8/50` 字数）→ 所属分类（下拉）→ 商品价格（数字，前缀 `¥`）→ 库存数量（整数）→ 上架状态（开关 40 × 22 + 文案「上架销售」+ 12px 灰色说明「关闭后商品不在前台展示，仍保留在列表中」）。
- 校验时机：失焦校验；错误态 = 控件边框 `--danger-600` + 3px `rgba(220,38,38,.12)` 外发光 + 下方 12px 红字（带 12px 圆形感叹号图标），如「价格最多 2 位小数，且不能小于 0」。提交失败保留用户输入，首个错误字段滚动到可视区。

### 4.5 删除确认弹窗

宽 420px；标题「删除商品 / 删除分类」；正文为 28px 圆形警告图标（`--danger-50` 底、`--danger-600` 图标）+「确定要删除分类「冲调饮品」吗？」+ 12px 灰色说明「删除后不可恢复…」；底部「取消」默认按钮 + 「删除」红色实心按钮（`--danger-600`），默认焦点在「取消」上。

| 层级 | 样式 | 使用场景 |

### 4.7 状态 Tag（关键语义）

| 状态 | 变量 / 色值 | 组成 |
| --- | --- | --- |
| 上架 | 底 `#ECFDF5` / 字 `#059669` / 边 `#A7F3D0` / 点 `#10B981` | 圆点 5px + 「上架」，高 24px、圆角 4px、字号 12px |
| 下架 | 底 `#F3F4F6` / 字 `#6B7280` / 边 `#E5E7EB` / 点 `#9CA3AF` | 同上 |

规则：绿色只代表「在售/正常」，灰色代表「已下线/中性」；不用红色表示下架（红色专属于删除与库存 0）。

### 4.8 空态

表格区域高 420px 垂直居中：120 × 120 插图（浅色圆底 + 文档 + 放大镜）→ 主文案 15px/500 `--text-2`「没有符合条件的商品」→ 13px `--text-4` 说明「尝试更换关键词，或清空筛选条件」→ 默认按钮「清空筛选」。`thead` 保留（表头不消失，避免布局跳动），表体 0 行，分页显示「共 0 条」。另两种空态：无任何商品用「还没有商品 + 点击右上角「新增商品」录入第一件商品」，分类为空用「还没有分类 + 先创建一个分类，再录入商品」。

### 4.9 加载态

表格 loading 用 Element Plus 遮罩（白底 72% + 旋转图标 24px `--primary-600`），最小显示 200ms 防闪烁，覆盖表体不覆盖表头；首屏骨架屏沿用表格结构（44px 表头 + 4 行 48px 灰条）；按钮 loading 时文案变「保存中…」「删除中…」并禁用；概览数字首载显示「—」，拿到数据后替换。

## 6. 数据与文案格式

- 价格：`¥` + 两位小数（`¥3.50`），右对齐，后端返回字符串，前端禁止二次 `toFixed` 造成精度偏差。
- 库存：纯整数右对齐；`0` 显示 `--danger-600`，`1 ~ 20` 显示 `--warning-600`，其余 `--text-2`。
- 时间：`yyyy-MM-dd HH:mm:ss`，左对齐，`--text-4` 弱化。
- 空值统一显示「—」，不显示空白或 `null`；商品总数、筛选结果等计数直接显示数字（0 也显示 0）。
- 数字与单位之间不加空格（`330ml`、`100g×8`）；中文标点全角，按钮文案用动宾结构（「新增商品」「保存」「清空筛选」）。
