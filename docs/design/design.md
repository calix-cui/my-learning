# 商品管理后台｜设计规范

> 本文给人读。需求见 docs/product/prd.md，实现见 frontend/。

画布 1440 × 900（桌面优先，≥1280 可用）；token 落在 `frontend/src/styles/index.css` 的 `--pa-*` 变量，并覆盖 Element Plus 的 `--el-color-*`。5 张设计稿见 §7。

## 1. 设计原则

1. **表格优先，装饰让位**：核心动作是「找商品 → 改商品」，视觉重心是表格行本身；不用斑马纹与渐变，只靠 1px 边框 + 8px 圆角分层。
2. **一套 token 走到底**：颜色 / 字号 / 间距 / 圆角 / 阴影只能取自 §2；页面里出现「临时调一下」的数值即视为缺陷。
3. **危险操作必须减速**：删除一律二次确认，红色只给删除与库存 0，并用文案说明后果（不可恢复 / 先处理商品）。
4. **状态双编码**：状态同时给颜色和文字（「上架 / 下架」），灰度与色觉障碍下仍可读。

### 2.3 间距与圆角、阴影

- 间距刻度（`--pa-space-1..8`）：4 图标与文字 · 8 标签与控件内边距 · 12 单元格左右 / 按钮组 · 16 卡片之间 · 24 内容内边距与弹窗内边距 · 32 大留白与弹窗最小边距。
- 圆角：4 标签·色块·分布条 / 6 按钮·输入框·分页·菜单项 / 8 卡片·统计卡·搜索区 / 12 弹窗。
- 阴影：`--shadow-sm` `0 1px 2px rgba(17,24,39,.04)` 卡片默认 · `--shadow-md` `0 4px 12px rgba(17,24,39,.10)` 卡片 hover·浮层 · `--shadow-lg` `0 16px 40px rgba(17,24,39,.18)` 弹窗。

## 3. 三条硬规则（踩过坑，原文保留）

1. **表格 thead 44px、行高严格 48px**：必须给 `tr` 设 `height: 48px`，只写 `td` 会掉到 44px；表头底 `#FAFBFC`、行分割线 `#F3F4F6`、hover `#F8FAFC`；价格与库存右对齐 + `tabular-nums`，状态与操作居中，ID 与时间用 `#9CA3AF`。
2. **状态色语义（不要混用）**：上架 = 绿 `#ECFDF5` 底 / `#059669` 字 / `#A7F3D0` 边 + 5px 绿点；下架 = 灰 `#F3F4F6` / `#6B7280` / `#E5E7EB` + 灰点；红 `#DC2626` 只给「删除」与「库存 0」；橙 `#D97706` 只给库存 1–20；「当前筛选结果」统计卡用中性灰，不给绿。
3. **92px 统计卡的行高预算**：label 13px/18px + value 28px/32px + sub 12px/16px + 上下 padding 13px = 92px。前端若把 value 写成 `line-height: 1.25`（35px）会溢出。

## 4. 组件规格

### 4.1 表格

列宽合计 1144 = 1440 − 200 侧栏 − 48 内容内边距 − 48 表格内边距，用 `table-layout: fixed` + `<colgroup>`，不用百分比：

| 表 | 列宽 |
| --- | --- |
| 商品列表 | ID 72 / 商品名称 308 / 分类 104 / 价格 116 / 库存 96 / 状态 104 / 创建时间 180 / 操作 164 |
| 分类管理 | ID 80 / 分类名称 440 / 商品数 220 / 创建时间 200 / 操作 204 |
| 概览·最近新增 | ID 80 / 商品名称 400 / 分类 140 / 价格 130 / 创建时间 260 / 状态 134 |

细则：表头 44px `#FAFBFC` 底、13px/500 `#6B7280`、下边框 1px `#E5E7EB`；表体行 48px、14px `#374151`、行下边框 `#F3F4F6`（末行无）；单元格左右 12px、单行 `ellipsis` + title；库存 0 用红、1–20 用橙、其余 `#374151`；价格 `¥` + 两位小数（后端已是字符串，前端不再 `toFixed`），时间 `yyyy-MM-dd HH:mm:ss`，空值统一「—」；操作列「编辑」文字按钮 + 1px × 12px 分隔线 + 「删除」危险文字按钮。

### 4.2 按钮

| 层级 | 样式 | 场景 |
| --- | --- | --- |
| 主按钮 | `#2563EB` 实心白字，高 32、左右 16、圆角 6、`0 1px 2px rgba(37,99,235,.24)`；hover `#1D4ED8`、按下 `#1E40AF`、禁用 `#BFDBFE` 底 + 白字 70% | 每视图仅一个：查询 / 新增商品 / 确定 |
| 默认按钮 | 白底 + `#D1D5DB` 1px 边框 + `#374151` 文字 | 重置、取消 |
| 危险按钮 | `#DC2626` 实心白字（按下 `#B91C1C`） | 删除确认 |
| 文字按钮 | 透明底，主色 / 危险色，高 28、左右 4 | 行内「编辑 / 删除」「查看全部」 |
| 图标按钮 | 32 × 32 白底描边 | 表格卡头「刷新」 |

### 4.3 输入框与表单

- 控件高 32px、圆角 6px、边框 `#D1D5DB`；hover 边框 `#9CA3AF`，focus 边框 `#2563EB` + 3px `rgba(37,99,235,.12)` 外发光；disabled 底 `#F9FAFB`、文字 `#9CA3AF`。
- 错误态：边框 `#DC2626` + 3px `rgba(220,38,38,.12)` 外发光 + 下方 12px 红字带 12px 感叹号图标，如「价格最多 2 位小数，且不能小于 0」；失焦即校验，提交失败保留输入并滚动到首个错误。
- 弹窗表单：宽 480px、圆角 12px、`--shadow-lg`；卡头 56px（16px/600 + 右上 20px 关闭图标），卡体 `24px 24px 8px`，卡底 64px、`#FCFCFD` 底、右对齐「取消」+「确定」；label 96px 右对齐、必填前置红色 `*`、行距 20px。

### 4.4 状态标签

高 24px、圆角 4px、12px 字号、5px 圆点；色值见 §3 第 2 条。绿色只代表「在售/正常」，灰色代表「已下线/中性」，不用红色表示下架。

### 4.5 统计卡

高 92px、内边距 13px 20px、圆角 8px、`--shadow-sm`；左侧 label 13px/18px `#6B7280` → value 28px/32px `#111827` → sub 12px/16px `#9CA3AF`，右侧 44 × 44 圆角 10px 浅色底图标块（中性卡用灰、成功语义才用绿）。

### 4.6 空态与加载态

- 空态：表格区高 420px 垂直居中，120 × 120 插图（浅色圆底 + 文档 + 放大镜）→ 15px/500 `#374151` 主文案 → 13px `#9CA3AF` 说明 → 默认按钮；`thead` 保留避免布局跳动，分页显示「共 0 条」。
- 加载态：表格用 Element Plus 遮罩（白 72% + 24px 主色转圈），最小 200ms 防闪烁，只盖表体不盖表头；按钮 loading 改文案「保存中…」并禁用；概览首屏数字显示「—」。

### 4.7 分页

左「共 N 条」13px `#6B7280`；右侧「10 条/页」下拉（可选 10 / 20 / 50）+ 上一页 + 页码 + 下一页（32 × 32、圆角 6px）；当前页 `#2563EB` 实心白字，其余白底 `#E5E7EB` 描边，禁用页文字 `#D1D5DB`、底 `#FAFBFC`。

### 4.8 布局壳（侧栏与顶栏）

侧栏 200px 白底、右侧 1px `#E5E7EB`：品牌区 56px（28 × 28 渐变方块 `#60A5FA` → `#2563EB`、圆角 8 + 14px/600 标题），菜单区四周 12px、菜单项 44px 圆角 6、图标 16px 与文字间距 10px，选中态 `#EFF6FF` 底 + `#2563EB` 字 + 左侧 3px × 24px 竖条，hover 底 `#F7F9FC`（**不用** `#F3F4F6`，避免与下架灰混淆）。顶栏 56px 白底 + 下边框：左「页面标题 18px/600 + 1px × 14px 竖线 + 面包屑 13px」，右「6px 绿点 + 12px 连接状态 + 28px 圆形头像 + 用户名」。内容区纵向 flex、`gap: 16px`，仅表格卡可 `flex: 1` 吃掉剩余高度（分页条贴卡片底）。

## 5. 页面规格

### 5.1 商品列表（`/products`）

纵向 = 3 张统计卡 92px（商品总数 / 分类数 / 筛选结果）+ 搜索区 64px + 数据卡（卡头 56 + 表格 + 分页 64）。搜索区含关键词输入 260px（前置放大镜，占位「搜索商品名称，回车查询」）、分类下拉 180px（「全部分类」）、主按钮「查询」、默认按钮「重置」、右侧 12px 提示；回车即查，重置清空关键词并把分类恢复「全部分类」、页码回 1。删除后当前页为空且 `page > 1` 时自动回上一页。

### 5.2 新增 / 编辑商品弹窗

新增与编辑共用 480px 弹窗，标题切换「新增商品 / 编辑商品」；字段顺序：商品名称（右侧 `8/50` 字数）→ 所属分类（下拉）→ 商品价格（数字，前缀 `¥`，最多 2 位小数）→ 库存数量（≥0 整数）→ 上架状态（开关 40 × 22 + 12px 说明「关闭后商品不在前台展示，仍保留在列表中」）。编辑走 PATCH 局部更新，成功后刷新当前页并保留页码。

### 5.3 分类管理（`/categories`）

顶部 3 张统计卡（分类总数 / 已归类商品 / 空分类）+ 分类表 + 底部「分类操作说明」卡（重名 409、有商品不可删、删除不可恢复 三条）。分类名前 6 × 6 圆角色块（有商品 `#3B82F6`，无商品 `#D1D5DB`）；商品数 = 右对齐数字 + 96 × 6px 占比条（轨 `#F3F4F6`、填充 `#3B82F6`，0 商品只画轨）。删除弹 420px 确认框：28px 圆形警告图标（`#FEF2F2` 底 + `#DC2626` 图标）+ 文案 + 12px 灰字后果说明 + 红色「删除」，默认焦点在「取消」；后端 409 时在弹窗内提示「该分类下还有商品，无法删除」。

### 5.4 概览（`/dashboard`）

4 张统计卡（商品总数 / 分类数 / 上架 / 下架）→ 左「各分类商品数」分布条（名称 + 条 + 数量 + 百分比，含 0 商品分类）与右「上架状态环形图 + 库存预警」（库存 ≤ 20 的最近条目，= 0 红、1–20 橙）→ 「最近新增商品」4 条。纵向预算：56 顶栏 + 24 + 92 + 16 + 378 + 16 + 294 + 24 = 900。

### 5.5 空态

三种：搜索无结果 →「没有符合条件的商品」+「尝试更换关键词，或清空筛选条件」+「清空筛选」；无任何商品 →「还没有商品」+「点击右上角「新增商品」录入第一件商品」；无分类 →「还没有分类」+「先创建一个分类，再录入商品」。插图与按钮位置见 §4.6。

## 6. 响应式与可访问性

- ≥1280px 才保证布局正确，1440 为设计基准；不承诺移动端，更窄时允许横向滚动。
- 侧栏 200px 固定不收缩，表格 fixed 布局 + 固定列宽，不随窗口拉伸出「胖列」。
- 对比度：正文 `#374151` on `#FFFFFF` ≈ 10.3:1，辅助 `#6B7280` ≈ 4.8:1 达 AA；`#9CA3AF` ≈ 2.5:1 只用于 ID、时间、占位等非关键信息，不承载唯一含义。
- 键盘可达：Tab 顺序 侧栏 → 顶栏 → 搜索区 → 表格操作 → 分页；焦点可见（主色边框 + 外发光）；弹窗 `Esc` 关闭，确认弹窗默认焦点在「取消」。
- 状态、错误、加载都必须有文字，不靠颜色单独传达（见原则 4）。
