现在开始为 AI Agent 应用设计整体技术架构。

参考学习项目：
https://github.com/datawhalechina/Hello-Agents

请以 Hello-Agents 的知识体系作为 Agent 能力建设的主要参考，但不要机械照搬其代码结构或技术选型。

项目最终定位是一个前后端分离、支持 Web 和跨平台桌面端的 AI Agent 应用。

### 一、架构设计目标

1. 前后端分离。
2. 前端与后端可以独立开发、测试和部署。
3. Agent 核心逻辑与 Web 框架解耦。
4. 后续能够扩展 Skill、MCP、Function Calling、RAG、记忆系统、多 Agent 协作等能力。
5. 支持本地开发。
6. 支持 Docker 容器化部署。
7. 支持云服务器一键部署。
8. 支持 macOS、Windows、Linux 桌面端打包。
9. 尽可能复用成熟开源组件和官方 SDK。
10. 避免过度设计，先满足当前 MVP 需求。

### 二、需要设计的模块

至少分析以下模块：

- Web 前端。
- 后端 API。
- Agent 核心引擎。
- LLM Provider 适配层。
- Tool / Function Calling。
- Skill 管理。
- MCP 接入。
- Prompt 管理。
- RAG。
- Memory。
- 用户与权限管理。
- 数据库。
- 文件存储。
- 日志与监控。
- 桌面端运行环境。
- 部署与交付系统。

对于暂时不需要实现的模块，标记为预留扩展能力，不要提前开发。

### 三、技术选型

对每个核心模块至少提供：

- 推荐方案。
- 可选替代方案。
- 优缺点。
- 社区成熟度。
- 与现有技术栈的兼容性。
- 对 AI 辅助开发的友好程度。
- 是否值得在 MVP 阶段引入。

尽量选择成熟、轻量、易于维护的技术。
